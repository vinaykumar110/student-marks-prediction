# Student Marks Prediction using Linear Regression

## About the Project
This beginner-friendly Machine Learning project uses Linear Regression to predict a student's marks based on the number of hours studied.

## Technologies Used
- Python
- Pandas
- Matplotlib
- Scikit-learn

## Machine Learning Workflow
1. Load and inspect the dataset.
2. Select study hours as the input feature and marks as the target.
3. Split the data into training and testing sets.
4. Train a Linear Regression model.
5. Predict marks using the trained model.
6. Evaluate the model using MAE, MSE, and R² score.

## How to Run

1. Clone or download this repository.
2. Install the required libraries:

   `pip install -r requirements.txt`

3. Run the Python script:

   `python main.py`

## Learning Objectives
- Understand supervised learning and regression.
- Learn train-test splitting.
- Train and evaluate a basic ML model.
